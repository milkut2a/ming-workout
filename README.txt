밍이의 짬짬이 운동 - 모바일 웹앱 파일

구성
- index.html: 실제 운동 기록 앱
- manifest.webmanifest: 홈 화면 설치 정보
- sw.js: 오프라인 캐시용 서비스 워커

중요
1) index.html만 휴대폰에서 열어도 기본 기록 기능을 테스트할 수 있습니다.
2) 기록은 해당 브라우저의 기기 안에 저장됩니다. 브라우저 데이터 삭제/기기 변경 시 사라질 수 있으니 앱의 '통계 > 기록 내보내기'로 백업하세요.
3) iPhone 홈 화면에 독립 앱처럼 설치하고 오프라인 기능까지 사용하려면 이 파일들을 HTTPS 주소로 게시해야 합니다. 게시 후 Safari에서 주소를 열고 공유 버튼 > '홈 화면에 추가'를 선택하세요.
4) 이 앱은 서버나 계정에 자동 동기화하지 않습니다. 다른 기기와 기록을 공유하려면 백업/불러오기를 이용하세요.
